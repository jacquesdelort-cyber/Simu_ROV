Design Détaillé - Simulateur ROV

Document de spécification technique pour l'implémentation d'un simulateur de ROV (Remotely Operated Vehicle) avec modélisation physique complète du système ROV-Câble-Bateau.

1. Architecture générale

Le simulateur ROV est conçu comme une application web hybride avec une séparation claire entre le moteur de calcul (backend) et l'interface utilisateur (frontend).

1.1. Composants principaux

  • Backend Python : moteur de calcul numérique pour la résolution des équations différentielles
  • Frontend Web : interface utilisateur et visualisation (HTML/CSS/JavaScript)
  • Communication temps réel : WebSocket pour le streaming des données de simulation

1.3. Flux de communication

Flux de commande (Frontend → Backend)

  1. Utilisateur modifie les paramètres ou commandes dans l'IHM
  2. Frontend envoie les commandes via WebSocket ou API REST
  3. Backend reçoit et valide les commandes
  4. Moteur de simulation intègre les nouvelles commandes

Flux de données (Backend → Frontend)

  1. Moteur de simulation calcule l'état du système à chaque pas de temps
  2. Backend sérialise l'état (positions, vitesses, tensions, etc.)
  3. Données envoyées via WebSocket en streaming (~30-60 Hz)
  4. Frontend reçoit et met à jour la visualisation

2.1.3. Méthodes de résolution numérique

Pour les équations différentielles ordinaires (ROV, Bateau)

Runge-Kutta d'ordre 4 (RK4) - Méthode explicite

  • Précision : Ordre 4 (erreur locale O(h⁵))
  • Stabilité : Bonne pour systèmes non-raides
  • Implémentation : Via scipy.integrate.solve_ivp avec méthode 'RK45'

Runge-Kutta adaptatif (Dormand-Prince)

  • Précision : Ordre 5, contrôle d'erreur automatique
  • Avantage : Pas de temps adaptatif selon la précision requise
  • Implémentation : Méthode par défaut de solve_ivp

Pour les équations aux dérivées partielles (Câble)

Recommandation initiale : Utiliser l'approche Quasi-statique avec différences finies pour débuter. C'est stable, rapide et offre un bon compromis précision/performance.

Option A - Différences Finies + Quasi-statique (Recommandé)

  • Discrétisation spatiale : N segments du câble (N=20 à 100)
  • Méthode : Résolution quasi-statique à chaque pas de temps
  • Résolution : Méthode de Newton pour conditions aux limites
  • Avantages :
    • Stable et rapide
    • Bon compromis précision/performance
    • Moins de complexité que méthode dynamique complète
  • Inconvénient : Ne capture pas la dynamique rapide du câble

Option B - Différences Finies + Dynamique

  • Discrétisation spatiale : Différences finies pour ∂/∂s
  • Intégration temporelle : Méthode d'Euler ou RK4 pour ∂/∂t
  • Méthode : Système couplé ROV-Câble-Bateau résolu simultanément
  • Avantage : Plus précis pour dynamique rapide
  • Inconvénient : Plus complexe, plus coûteux en calcul

Option C - Méthode des lignes (Method of Lines)

  • Principe : Transformation EDP → système d'ODE via discrétisation spatiale
  • Résolution : solve_ivp sur le système d'ODE couplé
  • Avantage : Bon compromis précision/complexité

4. Détails techniques

4.1. Discrétisation du câble

Le câble de longueur L(t) est discrétisé en N segments :

  • Positions nodales : x[i](t), y[i](t) pour i = 0..N
  • i=0 : point d'attache ROV
  • i=N : point d'attache bateau (moulinet)
  • Pas spatial : Δs = L(t) / N (adaptatif si L variable)
  • Recommandation N : 20 à 100 segments selon précision requise

4.2. Schéma numérique pour le câble

Approche quasi-statique (recommandée initialement)

À chaque pas de temps t :
  1. Résoudre équations d'équilibre du câble (système non-linéaire)
     - Utiliser scipy.optimize.root avec méthode de Newton
     - Variables : tensions T[i], angles θ[i] pour i=0..N
  2. Calculer T(s), θ(s) et positions x(s), y(s) par intégration
  3. Extraire T(0,t) et θ(0,t) au niveau ROV
  4. Intégrer ODE ROV avec T(0,t) comme force appliquée
  5. Extraire T(L,t) et θ(L,t) au niveau bateau
  6. Intégrer ODE Bateau avec T(L,t) comme force

Méthode des différences finies

  • Dérivées spatiales :
    • ∂f/∂s ≈ (f[i+1] - f[i]) / Δs (différence avant)
    • ∂f/∂s ≈ (f[i+1] - f[i-1]) / (2Δs) (différence centrée, plus précis)
  • Pour équations d'équilibre : système non-linéaire à résoudre (Newton-Raphson)
  • Conditions aux limites :
    • ROV : x[0]=x_ROV, y[0]=y_ROV
    • Bateau : x[N]=x_bateau, y[N]=0

4.3. Intégration temporelle système complet

Schéma d'intégration couplé

1. État initial :
   - Positions : x_ROV(0), y_ROV(0), x_bateau(0)
   - Vitesses : vx_ROV(0), vy_ROV(0), vx_bateau(0)
   - Configuration câble : L(0), configuration initiale (caténaire statique)

2. Pour chaque pas de temps Δt :
   a. Calculer forces sur câble :
      - Traînée à chaque segment : F_drag[i] = f(v_rel[i])
      - Poids apparent : w[i] = (ρ_cable - ρ_eau) * A_cable * g * Δs
   
   b. Résoudre équations câble (quasi-statique ou dynamique) :
      - Résoudre système non-linéaire pour T[i], θ[i]
      - Calculer positions x[i], y[i] par intégration
   
   c. Extraire T(0,t), θ(0,t) au niveau ROV
   
   d. Calculer forces sur ROV :
      - Traînée : F_drag,ROV
      - Tension câble : T(0,t) * [cos(θ(0,t)), sin(θ(0,t))]
      - Forces propulsion : Fx_ROV, Fy_ROV
      - Poussée Archimède
   
   e. Intégrer ODE ROV (RK4) :
      - dvx_ROV/dt = Fx_total / m_ROV
      - dvy_ROV/dt = Fy_total / m_ROV
      - dx_ROV/dt = vx_ROV
      - dy_ROV/dt = vy_ROV
   
   f. Extraire T(L,t), θ(L,t) au niveau bateau
   
   g. Calculer forces sur bateau :
      - Tension câble : T(L,t) * cos(θ(L,t))
      - Force propulsion : F_prop,bateau (pour atteindre vx_bateau_cmd)
   
   h. Intégrer ODE Bateau :
      - dvx_bateau/dt = Fx_total / m_bateau
      - dx_bateau/dt = vx_bateau
   
   i. Mettre à jour L(t) si commande dL_dt ≠ 0 :
      - L(t+Δt) = L(t) + dL_dt * Δt
   
   j. Envoyer état via WebSocket (si temps d'affichage)

4.5. Performance et optimisation

Points critiques

  • Résolution équations câble : Préférer méthode quasi-statique pour performance
  • Vectorisation NumPy : Éviter boucles Python, utiliser opérations vectorielles
  • Pas de temps adaptatif : solve_ivp gère automatiquement
  • WebSocket : Envoyer états à ~30-60 Hz (fréquence d'affichage, pas nécessairement fréquence de calcul)

Optimisations possibles

  • Numba JIT : Compiler fonctions critiques (calcul traînée sur câble, etc.)
  • Résolution câble en parallèle : Si multi-threading disponible
  • Interpolation : Réduire nombre de noeuds câble pour visualisation (garder tous les noeuds pour calcul)
  • Cache : Mettre en cache résultats de calculs coûteux (courant en fonction de y)

5.2. Cycle de simulation

Boucle principale de simulation

1. Initialisation :
   - Charger paramètres système
   - Initialiser état initial (positions, vitesses)
   - Créer discrétisation câble
   - Se connecter WebSocket

2. Boucle de simulation (si running) :
   WHILE running:
     a. Lire commandes en attente (Fx_ROV, Fy_ROV, vx_bateau_cmd, dL_dt)
     
     b. Résoudre système couplé pour un pas de temps Δt :
        - Résoudre câble (quasi-statique)
        - Intégrer ODE ROV
        - Intégrer ODE Bateau
        - Mettre à jour L(t)
     
     c. Si temps d'affichage (1/30 ou 1/60 Hz) :
        - Sérialiser état complet
        - Envoyer via WebSocket
     
     d. Vérifier conditions d'arrêt (timeout, erreur, etc.)
     
     e. Attendre Δt (ou utiliser boucle non-bloquante)

3. Arrêt :
   - Sauvegarder dernières données
   - Fermer WebSocket
   - Libérer ressources

6. Exemples de code

6.1. Backend - Modèle ROV (Python)

import numpy as np from scipy.integrate import solve_ivp class ROVModel: def __init__(self, params): self.m_ROV = params['m_ROV'] self.a = params['a'] self.b = params['b'] self.h = params['h'] self.V_ROV = self.a * self.b * self.h self.Sx_ROV = self.a * self.h self.Sy_ROV = self.a * self.b self.Cx_ROV = params['Cx_ROV'] self.Cy_ROV = params['Cy_ROV'] self.rho_eau = params['rho_eau'] self.g = params['g'] def compute_drag_force(self, vx, vy, V_courant_y): """Calcule la force de traînée""" vx_rel = vx - V_courant_y vy_rel = vy F_drag_x = -0.5 * self.rho_eau * self.Cx_ROV * self.Sx_ROV * \ vx_rel * abs(vx_rel) F_drag_y = -0.5 * self.rho_eau * self.Cy_ROV * self.Sy_ROV * \ vy_rel * abs(vy_rel) return np.array([F_drag_x, F_drag_y]) def compute_buoyancy_force(self): """Calcule la poussée d'Archimède""" F_buoy = self.rho_eau * self.V_ROV * self.g return np.array([0, F_buoy]) def compute_gravity_force(self): """Calcule le poids""" F_weight = -self.m_ROV * self.g return np.array([0, F_weight]) def derivative(self, t, state, T0, theta0, F_prop, V_courant_func): """ Calcule les dérivées pour solve_ivp state = [x_ROV, y_ROV, vx_ROV, vy_ROV] """ x_ROV, y_ROV, vx_ROV, vy_ROV = state # Forces F_drag = self.compute_drag_force(vx_ROV, vy_ROV, V_courant_func(y_ROV)) F_buoy = self.compute_buoyancy_force() F_weight = self.compute_gravity_force() F_cable = np.array([ T0 * np.cos(theta0), T0 * np.sin(theta0) ]) F_total = F_drag + F_buoy + F_weight + F_cable + F_prop # Dérivées dvx_dt = F_total[0] / self.m_ROV dvy_dt = F_total[1] / self.m_ROV dx_dt = vx_ROV dy_dt = vy_ROV return np.array([dx_dt, dy_dt, dvx_dt, dvy_dt])

6.2. Backend - Modèle Câble (Python)

import numpy as np from scipy.optimize import root class CableModel: def __init__(self, params): self.d = params['d'] self.rho_cable = params['rho_cable'] self.Cx_cable = params['Cx_cable'] self.rho_eau = params['rho_eau'] self.g = params['g'] self.A_cable = np.pi * (self.d / 2)**2 self.N = params['N_segments'] def discretize(self, L): """Crée la discrétisation du câble""" self.ds = L / self.N self.s = np.linspace(0, L, self.N + 1) def compute_drag_distributed(self, v_rel_func): """Calcule la traînée distribuée""" F_drag = np.zeros((self.N + 1, 2)) for i in range(self.N + 1): v_rel = v_rel_func(self.s[i]) v_rel_norm = np.linalg.norm(v_rel) if v_rel_norm > 0: F_drag[i] = -0.5 * self.rho_eau * self.Cx_cable * \ self.d * v_rel_norm * v_rel return F_drag def compute_apparent_weight(self): """Calcule le poids apparent par unité de longueur""" w = (self.rho_cable - self.rho_eau) * self.A_cable * self.g return w def solve_quasi_static(self, x_ROV, y_ROV, x_boat, y_boat, V_courant_func): """ Résout les équations d'équilibre du câble (quasi-statique) Retourne T, theta, x, y pour chaque noeud """ # Variables : T[i], theta[i] pour i=0..N n_vars = 2 * (self.N + 1) def residuals(vars): T = vars[:self.N+1] theta = vars[self.N+1:] # Conditions aux limites position x = np.zeros(self.N + 1) y = np.zeros(self.N + 1) x[0] = x_ROV y[0] = y_ROV x[-1] = x_boat y[-1] = y_boat # Résidus pour équations d'équilibre res = np.zeros(n_vars) # Intégration des équations d'équilibre w = self.compute_apparent_weight() for i in range(self.N): # Équation horizontale res[i] = (T[i+1] * np.cos(theta[i+1]) - T[i] * np.cos(theta[i])) / self.ds # Ajouter traînée si nécessaire # Équation verticale res[i + self.N + 1] = (T[i+1] * np.sin(theta[i+1]) - T[i] * np.sin(theta[i])) / self.ds - w # Géométrie x[i+1] = x[i] + np.cos(theta[i]) * self.ds y[i+1] = y[i] + np.sin(theta[i]) * self.ds # Conditions aux limites position res[self.N] = x[-1] - x_boat res[2*self.N + 1] = y[-1] - y_boat return res # Estimation initiale (caténaire) T0 = np.ones(self.N + 1) * 100 # Tension initiale theta0 = np.linspace(np.arctan2(y_boat - y_ROV, x_boat - x_ROV), 0, self.N + 1) x0 = np.concatenate([T0, theta0]) # Résolution sol = root(residuals, x0, method='lm') if not sol.success: raise ValueError("Échec résolution équations câble") T = sol.x[:self.N+1] theta = sol.x[self.N+1:] # Recalculer positions x = np.zeros(self.N + 1) y = np.zeros(self.N + 1) x[0] = x_ROV y[0] = y_ROV for i in range(self.N): x[i+1] = x[i] + np.cos(theta[i]) * self.ds y[i+1] = y[i] + np.sin(theta[i]) * self.ds return T, theta, x, y

7. Guide d'implémentation étape par étape

Phase 1 - Prototype backend : Modèle ROV seul

Objectifs

  • Implémenter modèle physique ROV
  • Résoudre ODE ROV avec solve_ivp
  • Valider calculs forces (traînée, poids, poussée Archimède)

Étapes

  1. Créer classe ROVModel avec paramètres
  2. Implémenter calcul des forces
  3. Implémenter fonction dérivée pour solve_ivp
  4. Résoudre ODE pour cas simple (sans câble, sans courant)
  5. Ajouter courant et validation

Tests

  • ROV en chute libre verticale (sans propulsion)
  • ROV avec flottabilité neutre (équilibre vertical)
  • ROV avec propulsion horizontale constante

Phase 2 - Câble statique

Objectifs

  • Implémenter modèle câble avec différences finies
  • Résoudre équations d'équilibre (caténaire statique)
  • Valider forme caténaire pour cas connu

Étapes

  1. Créer classe CableModel
  2. Implémenter discrétisation
  3. Implémenter résolution quasi-statique (Newton)
  4. Valider avec cas caténaire classique (deux points fixes, poids uniquement)
  5. Ajouter traînée

Phase 3 - Couplage ROV-Câble-Bateau

Objectifs

  • Coupler résolution câble et ODE ROV/Bateau
  • Implémenter solveur système couplé
  • Valider conservation énergie/momentum

Étapes

  1. Créer classe CoupledSolver
  2. Implémenter boucle d'intégration temporelle
  3. À chaque pas de temps :
    1. Résoudre câble (quasi-statique)
    2. Extraire T(0), θ(0) pour ROV
    3. Intégrer ODE ROV
    4. Extraire T(L), θ(L) pour bateau
    5. Intégrer ODE Bateau
  4. Valider avec simulation complète

Phase 4 - Frontend basique : Visualisation 2D

Objectifs

  • Créer interface HTML basique
  • Implémenter visualisation 2D avec Canvas
  • Connecter WebSocket et afficher données

Étapes

  1. Créer page HTML avec Canvas
  2. Implémenter client WebSocket
  3. Dessiner ROV, câble, bateau en 2D
  4. Animer avec données reçues
  5. Ajouter contrôles basiques (start/stop)

Phase 5 - Frontend avancé : Visualisation 3D

Objectifs

  • Migrer vers Three.js
  • Créer visualisation 3D
  • Ajouter contrôles caméra
  • Implémenter panneau de contrôle complet

Étapes

  1. Intégrer Three.js
  2. Créer scène 3D (ROV, câble, bateau)
  3. Implémenter contrôles caméra (OrbitControls)
  4. Ajouter panneau paramètres
  5. Ajouter panneau commandes temps réel
  6. Ajouter graphiques temps réel (Chart.js)

Phase 6 - Optimisation et finalisation

Objectifs

  • Optimiser performance
  • Gérer erreurs et cas limites
  • Ajouter tests unitaires
  • Documentation utilisateur

Étapes

  1. Profiler et optimiser boucles critiques
  2. Ajouter gestion erreurs (connexion perdue, divergence simulation, etc.)
  3. Implémenter tests unitaires pour modèles
  4. Ajouter export données (CSV)
  5. Créer documentation utilisateur
